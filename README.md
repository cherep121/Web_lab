## 🛠 Стек
- HTML5 (семантические теги)
- CSS3 (Flexbox, Grid, media queries, CSS-переменные)
- **jQuery 3.7.1** (CDN)
- **AJAX / JSON**
- Git

## 📁 Структура
```
Web_lab/
├─ index.html
├─ css/
│ └─ styles.css
├─ js/
│ └─ script.js <-- динамика на jQuery
├─ data/
│ └─ portfolio.json <-- данные для галереи
├─ images/
│ ├─ avatar.png
│ ├─ image.png
│ ├─ image2.png
│ ├─ image3.png
│ └─ image4.png
├─ README.md
└─ .gitignore
```
**Описание:**
- `index.html` — основная страница-визитка
- `css/styles.css` — все стили, включая адаптив
- `js/script.js` — весь JS-код на jQuery (меню, галерея, форма, карусель, подсветка меню, кнопка «Вверх»)
- `data/portfolio.json` — данные о работах для динамической галереи
- `images/` — аватар и скриншоты проектов
- `README.md` — документация проекта
- `.gitignore` — исключения для Git
